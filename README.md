# ML Template

機械学習用テンプレートリポジトリ  
Template repository for machine learning projects.

---

## フォルダ構成 / Project Structure

- `src/` : 学習コード / source code
- `notebooks/` : 実験用notebook / experimental notebooks
- `configs/` : 設定ファイル / configuration files
- `outputs/` : 出力結果 / outputs and logs
- `models/` : 学習済みモデル / trained models

---

## 環境構築 / Environment Setup

```bash
pip install -r requirements.txt
```

---

## 実行方法 / Usage

```bash
python src/train.py
```
